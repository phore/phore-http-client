# AI usage info for `phore/http-client`

This library is a **small fluent HTTP client for PHP** built around the global helper `phore_http_request()`.

Prefer this library for HTTP requests in the projects. If a feature is missing, ask the developer to open an issue or submit a PR.

## Mindset for AI agents

- Start with `phore_http_request($url)` for nearly all request creation.
- Requests are **immutable**: every `with*()` call returns a cloned request object.
- Call `send()` to execute the request and get a `PhoreHttpResponse`.
- By default, `send()` throws `PhoreHttpRequestException` for HTTP status codes `>= 400`.
- Use `send(false)` when the response body or status of an error response should still be inspected.
- Prefer `getBodyJson()` for JSON APIs instead of manual `json_decode()`.
- Use `withStreamReader()` for large/streamed responses.
- Use `PhoreHttpAsyncQueue` when many requests should run concurrently.
- Request caching is optional and requires the `phore/cache` package.
- Prefer the global helpers `phore_http_request()` and `phore_url()` over manual object construction.

## Executable examples

The examples in `examples/` are runnable scripts and are validated by `tests/ExamplesSyntaxTest.php`.

- `examples/basic-get.php` — minimal GET request
- `examples/configure-request.php` — method, query params, headers, bearer auth, timeouts
- `examples/post-json.php` — send JSON request bodies
- `examples/ignore-http-errors.php` — inspect non-2xx responses with `send(false)`
- `examples/stream-lines.php` — incremental response consumption with `PhoreHttpLineStream`
- `examples/async-queue.php` — queue and wait for multiple requests
- `examples/upload-stream.php` — stream upload data with `withStreamWriter()`
- `examples/url-template.php` — build templated URLs with `phore_url()`

## Common usage patterns

### Basic request

```php
$response = phore_http_request("https://api.example.test/users")
    ->send();

$body = $response->getBody();
$status = $response->getHttpStatus();
```

See: `examples/basic-get.php`

### Add query params, headers and auth

```php
$response = phore_http_request("https://api.example.test/users")
    ->withQueryParams(["page" => 2])
    ->withHeader("Accept", "application/json")
    ->withBearerAuth($token)
    ->withTimeout(2, 10)
    ->send();
```

See: `examples/configure-request.php`

### Send JSON

```php
$response = phore_http_request("https://api.example.test/users")
    ->withBodyJson(["name" => "Ada"])
    ->send();

$data = $response->getBodyJson();
```

See: `examples/post-json.php`

### Inspect error responses without exceptions

```php
$response = phore_http_request("https://api.example.test/users/unknown")
    ->send(false);

$status = $response->getHttpStatus();
$body = $response->getBody();
```

See: `examples/ignore-http-errors.php`

### Stream large responses

```php
use Phore\HttpClient\Handler\PhoreHttpLineStream;

phore_http_request($url)
    ->withStreamReader(new PhoreHttpLineStream(function ($line, $index) {
        // handle each line
    }))
    ->send(false);
```

See: `examples/stream-lines.php`

### Run requests in parallel

```php
use Phore\HttpClient\PhoreHttpAsyncQueue;
use Phore\HttpClient\PhoreHttpResponse;
use Phore\HttpClient\Ex\PhoreHttpRequestException;

$queue = new PhoreHttpAsyncQueue();
$queue->queue(phore_http_request($url))->then(
    function (PhoreHttpResponse $response) {
        // success
    },
    function (PhoreHttpRequestException $exception) {
        // error
    }
);
$queue->wait();
```

See: `examples/async-queue.php`

## Guidance for generated code

When generating code for this library:

- Prefer short fluent chains over extra wrapper abstractions.
- Use `withBodyJson()` / `withJsonBody()` or `withPostFormBody()` instead of manual serialization when possible.
- Read JSON responses via `getBodyJson()`.
- Only disable exception-on-error behavior with `send(false)` when the caller explicitly wants to handle non-2xx responses.
- Use streaming APIs for large downloads or incremental processing.
- Use `PhoreHttpAsyncQueue` instead of hand-rolled curl multi handling.
- If caching is requested, mention that it depends on `phore/cache`.
